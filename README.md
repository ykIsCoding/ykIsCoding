## Selected Projects
 
### Healthenvision: Multi-Agent Health Intervention System
*Final Year Project (Grade: A)*
 
Multi-agent LLM system built on GPT-5 and OpenAI TTS, deployed on Azure Machine Learning, that delivers personalised Just-In-Time Adaptive Interventions. Integrates a Linear Thompson Sampling multi-armed bandit with LLMs for adaptive recommendations, a Kotlin WearOS app for real-time biometric capture, and G-Eval for pipeline evaluation. Validated in an IRB-approved user study and published as a preprint.
 
`Python` `Azure ML` `OpenAI API` `Multi-Agent Systems` `G-Eval` `Kotlin`
 
### Agentic AI Logistics Optimiser
*PSA CodeSprint 2025 Hackathon*
 
Multi-step agentic system built with CrewAI and deployed on Google Cloud Run for autonomous logistics decision-making.
 
`CrewAI` `Python` `GCP Cloud Run`
 
### RAG Chatbot with QLoRA Style Transfer
 
LLM chatbot with a semantic RAG pipeline combining BM25 search, re-ranking, query expansion, and Hypothetical Document Embeddings (HyDE). Includes QLoRA adapter training on Qwen 0.5B for text style transfer.
 
`RAG` `HyDE` `BM25` `QLoRA` `Qwen`
